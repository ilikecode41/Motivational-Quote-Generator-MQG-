📘 MQG — Motivational Quote Generator
MQG is a small Python program that gives you a randomly generated motivational quote.
Just type quote, wait a moment, and enjoy your inspiration boost.

🚀 How to Run
Make sure you have Python 3 installed.

Download or copy the file (for example: mqg.py).

Open your terminal or command prompt.

Navigate to the folder where the file is saved:

Code
cd path/to/your/file
Run the program:

Code
python mqg.py
🎯 How It Works
When you start the program, you’ll see:

Code
Welcome to the MQG! (Motivational Quote Generator)
Please Enter "quote" To Randomly Generate a Motivational Quote
✔ If you type quote
The program begins generating your quote

Shows a short loading animation

Waits 3 seconds

Displays one of 10 motivational quotes chosen at random

❌ If you type anything else
The program tells you that you didn’t type quote

You get one more chance to type it correctly

If you still don’t type quote, the program ends

💬 Example Output
Code
Please Enter "quote" To Randomly Generate a Motivational Quote
quote
Please Wait As We Generate Your Quote
----------GENERATING----------
----------FINISHED----------
“You don’t need to be perfect, just persistent.”
📄 Notes
The program only restarts once if the input is incorrect.

To get another quote, simply run the program again.

All quotes are stored directly in the script.
